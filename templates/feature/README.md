# Feature migration template

Copy this directory to `src/app/features/<feature>`, replace `__FEATURE__` and
`__Feature__`, and rename the template files to normal `.ts`, `.html`, and
`.scss` extensions. Follow `docs/MigrationGuide.md`; do not invent new markup
when a matching prototype page exists.

Delete this instruction file from the copied feature and add a short feature
README containing its prototype source function/page and any verified
intentional differences.
