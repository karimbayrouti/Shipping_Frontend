# Vision

Build an enterprise frontend **platform**, not just a shipping app: a foundation
that supports 150+ screens, Arabic/English with live RTL/LTR, a mixed-seniority
team, and years of maintenance — where the first product is the Shipping
Management System and the React prototype serves as its executable
specification.

Success criteria:

1. A new developer contributes production-quality code on day 2.
2. Any two features look like they were written by the same person.
3. The linter — not the reviewer — catches architectural violations.
4. The frontend runs fully on mock data until the ASP.NET backend lands.
5. Platform code contains zero shipping vocabulary (reuse for ERP #2).
