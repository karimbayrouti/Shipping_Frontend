# Definition of Done

Work is done when ALL of the following hold:

- [ ] Lint, tests and production build pass locally and in CI.
- [ ] Code follows `docs/Standards.md` (sizes, naming, signals, tokens).
- [ ] UI work passes the four-way check (LTR/RTL × light/dark) + keyboard.
- [ ] Migrated UI is compared with the Shipping Prototype in every supported visual mode.
- [ ] User-facing strings are translation keys (from Phase 3 onward), AR + EN.
- [ ] Errors and empty/loading states are designed, not accidental.
- [ ] Docs touched by the change are updated in the same PR.
- [ ] Reviewed and approved per `ReviewChecklist.md`.

"Works on my machine", "will document later" and "temporary hack" are not done.
