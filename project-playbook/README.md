# Project Playbook

a process doc is added only when the activity it governs starts (release and
deployment docs arrive with the first release).

| Doc                                        | Governs                                     |
| ------------------------------------------ | ------------------------------------------- |
| [Vision.md](Vision.md)                     | Why this platform exists, in one page       |
| [GitStrategy.md](GitStrategy.md)           | Branching, commits, PR flow                 |
| [ReviewChecklist.md](ReviewChecklist.md)   | What a reviewer checks, in order            |
| [DefinitionOfDone.md](DefinitionOfDone.md) | When work is actually finished              |
| [DecisionLog.md](DecisionLog.md)           | Amendments to the Charter, dated and argued |
