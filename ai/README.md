# AI Prompt Library

Reviewed, versioned prompts for AI-assisted development (Charter AD-19).
Start-small set per the YAGNI amendment — add a prompt file when a workflow
proves recurring, remove ones nobody uses.

| Prompt file (added when first needed) | Use for                                     |
| ------------------------------------- | ------------------------------------------- |
| `feature-generation.md` _(Phase 7)_   | Scaffolding a feature from the template     |
| `component-generation.md` _(Phase 4)_ | Building a `ui-*` component to the DoD      |
| `code-review.md` _(Phase 3)_          | Pre-review self-check against the checklist |
| `testing.md` _(Phase 3)_              | Generating specs for stores/repositories    |
| `bug-investigation.md` _(Phase 3)_    | Structured debugging with the error funnel  |

Every prompt file states: when to use it · what context to paste (files, docs)
· what good output looks like · what to double-check by hand afterwards.
