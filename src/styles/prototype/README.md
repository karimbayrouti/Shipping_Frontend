# Prototype style contract

These five files are exact copies of `Shipping/prototype-html/css` and are
loaded globally in source order by `angular.json`.

Do not edit them to solve one Angular screen. Change the Shipping Prototype
first, update its static kit, then copy the complete changed file here. Put
screen-only CSS beside that screen.

The physical `left` declarations in the contract position pixels inside the
brand crop and center an overlay; they are direction-independent exceptions.
